Diagnostic médical assisté par Machine Learning

Cette application déploie deux modèles de classification entraînés avec la méthode des K plus proches voisins (KNN) et la bibliothèque scikit-learn. Choisissez un outil de diagnostic ci-dessous.

🎗️

Cancer du sein

Prédiction du caractère Benign ou Malignant d'une tumeur à partir de 30 mesures issues d'une image numérisée.

Breast Cancer Wisconsin Dataset
🩸

Diabète

Prédiction du risque de diabète à partir de 8 mesures médicales (glycémie, IMC, âge, etc.).

Pima Indians Diabetes Dataset

Comment ça marche ?

  1. Renseignez les mesures demandées dans le formulaire (des valeurs par défaut sont pré-remplies à titre d'exemple).
  2. Les données sont mises à l'échelle avec le même scaler que celui utilisé lors de l'entraînement.
  3. Le modèle KNN calcule la classe la plus probable parmi les exemples les plus proches.
  4. Le résultat, ainsi que le niveau de confiance du modèle, s'affiche instantanément.
